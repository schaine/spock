# Spock has no built-in AI; the Owner interprets with Claude Desktop

Spock is an "intelligence" platform, yet it runs no AI model of its own. It collects Indicators, charts them, and finds Flags, Divergences and Patterns with fixed, written-down rules. The Owner interprets them with Claude Desktop on their existing Pro plan, through a private connector that only the Owner's account can use. The connector can read Spock's data and save an Insight. We chose this over Insights written automatically by an AI model inside Spock because it adds no per-use AI cost, keeps every interpretation the Owner's own work, and turns Insights into raw material for the Owner's content (a newsletter, videos).

Approved by the Owner, `schaine`, on 2026-11-18, during the first grill (issue #2).

## Considered options

- AI-written Insights inside Spock, labelled as such, with a monthly spending cap. Rejected: it costs money for every Insight, and the Owner wants to do the interpreting.
- AI drafts and the Owner approves. Rejected for the same cost, and because the Owner's time is still the bottleneck.

## Consequences

- Flags carry only a plain factual sentence from a fixed template, never an interpretation.
- Spock is no chatbot: Visitors cannot ask it questions.
